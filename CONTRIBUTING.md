# Contributions

This is a private proprietary project. External contributions are not accepted
unless a written agreement is signed before the contribution is submitted.

The agreement must define confidentiality, authorship, warranties of
originality, treatment of third-party materials, and the ownership or license
of the contributed code. A pull request, issue, message, or repository access
alone does not create such an agreement.

Do not submit personal data, customer documents, contracts, credentials,
signing certificates, API keys, production data, or third-party confidential
materials to this repository.
